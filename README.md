# Replication package

**Do Voluntary Industry Measures Shift Support for Stronger Environmental Governance?**
E. Keith Smith and Thomas Bernauer. *Environmental Research Letters* (accepted).
DOI: `<PLACEHOLDER — add on publication>`

This package reproduces every figure and table in the main text and Supplementary
Information from a public, anonymised extract of Swiss Environmental Panel (SEP)
Wave 12 data.

## Software

- **Stata 19.5** (StataNow SE), macOS (Darwin). Set at the top of every script via
  `version 19.5`. Should also run under Stata 18/19; the `version` statement guards
  syntax compatibility.
- **User-written commands** (installed automatically by `master.do`; pull date
  2026‑09‑18):

  | Command | Source | Purpose |
  |---|---|---|
  | `blindschemes` | SSC (`ssc install blindschemes`) | `plotplain` graph scheme |
  | `coefplot` | SSC (`ssc install coefplot`) | coefficient / AME plots |
  | `catplot` | SSC (`ssc install catplot`) | categorical distribution plot (Fig 5a) |
  | `grc1leg2` | **not on SSC** — `net install grc1leg2, from(http://digital.cgdev.org/doc/stata/MO/Misc)` | combined graphs with one shared legend |

  `margins`, `marginsplot`, `putexcel`, `factor`, `mlogit`, `alpha` are built-in.

## How to run

1. Open Stata in this folder (or edit the single `cd` line at the top of `master.do`
   to point at it).
2. Run:

   ```stata
   do master.do
   ```

`master.do` sets the working directory once, creates the output folders, installs the
required commands, sets a seed, opens a timestamped log in `logs/`, and runs every
analysis script in order against `data/public_food_waste_w12.dta`. All downstream
scripts use relative paths and inherit that working directory.

To confirm the public data reproduces the paper's headline numbers:

```stata
do check_reproduction.do
```

This prints sample sizes, baseline descriptives, and the headline coefficients next to
the values reported in the manuscript (see `logs/check_reproduction.log`).

**Expected runtime:** roughly 3–6 minutes on a recent laptop (most of it in the
Lin-adjusted robustness models and the marginsplot grids).
